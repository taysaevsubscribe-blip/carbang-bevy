# CarBang: демо-сцена для Unity (одиночная игра, 2 машины)

Ваш «Хорёк» (лёгкий полноприводный хэтчбек) против «Бизона» (тяжёлый грузовик под управлением ИИ) на арене-кольце «Свалка на закате». Бой до разбития или 5 минут, по истечении времени победа по нанесённому урону.

## Запуск

1. Unity 6 (6000.0 или новее), новый проект из шаблона **Universal 3D** (URP). Другие версии и Built-in RP не поддерживаются.
2. Скопировать папку `CarBang` в `Assets/` проекта. Дождаться импорта и компиляции.
3. Меню **CarBang → Собрать демо-сцену**. Создаётся `Assets/CarBang/Scenes/CarBangDemo.unity`, она же ставится первой в Build Settings, настраиваются тени URP (150 м, 2 каскада) и MSAA 4×.
4. **Play**.

Вся сцена (арена, машины, свет, небо, пост-обработка, интерфейс) строится кодом при запуске из компонента `DemoBootstrap`. В инспекторе этого компонента можно менять мастерство, агрессию и хитрость ИИ.

Если вмятины на кузове не появляются: **CarBang → Переимпортировать модели машин** (включает Read/Write у моделей).

## Управление

| Действие | Клавиатура и мышь | Геймпад |
|---|---|---|
| Газ / тормоз и задний ход | W / S (стрелки) | RT / LT |
| Руль | A / D (стрелки) | левый стик |
| Ручник | Пробел | A (Cross) |
| Нитро | Shift | B (Circle), LB |
| Пулемёт | ЛКМ, Ctrl, J | X (Square) |
| Масло | Q, L | RB, крестовина вниз |
| Поставить на колёса | R | Select |
| Взгляд назад | V | крестовина влево |
| Камера (близко, далеко, капот) | C | нажатие правого стика |
| Сигнал | H | нажатие левого стика |
| Пауза | Esc, P | Start |
| Заново (в паузе и на итогах) | Enter | Y (Triangle) |

Задний ход: остановиться и держать тормоз 0,3 с.

## Что есть в демо

- Подвеска на лучах, шины с уводом и кругом трения, стабилизаторы, прижим, помощь в повороте и в воздухе, автопереворот.
- Урон как в прототипе: по изменению скорости при ударе, броня берёт половину, защита от гибели с одного удара при 25+ HP, мгновенная гибель ниже 25 HP на ударе быстрее 120 км/ч. Узлы: радиатор, двигатель, проколы. Вмятины деформацией вершин.
- Пулемёт с перегревом и автонаводкой в конусе 9°, может пробить шину. Масло: 3 заряда, перезарядка 20 с.
- Бочки (взрываются от удара, огня и цепочкой), конусы и ящики с физикой.
- Бонусы: ремонт +35 (2 шт.), нитро (2 шт.), урон ×2 на 10 с (на вершине трамплина). Респаун 18 с.
- ИИ «Гоша Бизон»: гонка, охота, таран, отход после удара, засада у срезки, уклонение, ремонт, выход из застревания. Копит ярость и тогда хуже замечает масло. Реплики с селфи-камерой.
- Срезка через центр кольца с трамплином.
- Процедурные звуки (мотор по оборотам, удары, взрывы, пулемёт) с 3D-позиционированием и приглушением за стенами.
- Закатное освещение, мягкие тени, bloom, ACES, виньетка, SMAA.
- Интерфейс: HP и броня, перегрев, заряды масла, спидометр с передачей и нитро, полоса соперника и таймер, радар, светофор старта, всплывающие «БАМ!/ХРЯСЬ!/В ХЛАМ!», лента событий, пауза, итоги.

## Ограничения

- Код проверен компиляцией против заглушек API Unity 6, в самом редакторе не запускался. Возможны ошибки консоли или настройки баланса: присылайте текст ошибки или скриншот, правлю точечно.
- Модели машин Kenney Car Kit (низкополигональные, CC0). Это временная геометрия: замена на детализированные модели делается в `CarFactory` (поиск колёс по имени узла).
- Материалы и текстуры создаются кодом. Для сборки игры шейдеры удерживаются шаблонами в `Resources/CarBangMats` (их создаёт пункт меню из шага 3).

## Структура

```
Scripts/Core      точка входа, ввод, материалы и процедурные текстуры, правила урона, события
Scripts/Vehicle   параметры машин, физика, сборка машины из модели
Scripts/Damage    здоровье, узлы, вмятины, разбитие
Scripts/Weapons   пулемёт, масло
Scripts/AI        водитель-ИИ, реплики
Scripts/Map       арена, граф трассы, масло, бочки, бонусы
Scripts/FX        частицы, следы шин, дым, огонь
Scripts/Audio     синтез звуков, мотор
Scripts/Game      камера, ход боя, водитель-игрок
Scripts/UI        интерфейс
Editor            меню CarBang, импорт моделей
Resources         модели Kenney (CC0)
```

Ассеты и лицензии: `ASSETS.md`. Unity покажет README.md и ASSETS.md как текстовые ассеты, это нормально.
