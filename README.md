# CarBang: готовые сборки

Код и ассеты лежат в ветке `main`. Здесь только бинарные сборки.

## Linux 0.2.0 (x86_64, glibc 2.28+)

Скачать все файлы из папки `linux-0.2.0` в одну папку, затем:

```
sh join.sh
./CarBang-0.2.0-linux-x86_64/carbang.sh
```

`join.sh` склеивает части, проверяет SHA256 и распаковывает архив. Требования и пакеты для Ubuntu/Debian в `ЗАПУСК.txt`.

## Windows 0.2.0 (x64, Windows 10/11)

Установщик одним файлом: `windows-0.2.0/CarBang-Setup-0.2.0.exe` (47 МБ). Кнопка Download на странице файла. SHA256 в `windows-0.2.0/SHA256.txt`.

Установщик не подписан: SmartScreen покажет предупреждение, нажать «Подробнее» → «Выполнить в любом случае».
