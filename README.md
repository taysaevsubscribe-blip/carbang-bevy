# CarBang

Аркадные гонки на выживание в духе Carmageddon 2: таран, оружие на крыше и бортах, пешеходы, безумные бонусы, шесть карт с ловушками, карьера, гараж и сетевая игра по IP. Движок Bevy 0.19 (ECS), физика avian3d 0.7, GPU-частицы bevy_hanabi 0.19. Звук: файлы из пакета ассетов (CC0 и CC-BY, см. титры) плюс синтез в коде. Графика: свободные CC0-ассеты (ambientCG, Poly Haven, Kenney) плюс процедурные модели машин, карт и эффектов.

## Баланс (ТЗ v2, §7)

- Старт: до сигнала машины стоят на ручнике в нейтрали, ввод не применяется; первые 0,5 с после старта только вперёд; задний ход включается, если скорость ниже 5 км/ч и тормоз держится дольше 0,3 с; мёртвая зона осей 0,08.
- Прочность: кузов 100 + броня 50 (броня берёт половину каждого удара, пока не кончится), 1,5 с неуязвимости после старта и воскрешения.
- Урон от удара: `7,2 × max(0, |Δv| − 4 м/с)`, Δv собирается за удар (до 0,2 с) и не превышает физически возможного для скорости сближения. Лобовой таран на 80 км/ч в стоящую машину той же модели снимает в среднем 29% кузова (21–38% по моделям).
- Одиночный удар не уничтожает машину с кузовом ≥ 25: она остаётся на 1. Мгновенная гибель — только при кузове < 25 и ударе быстрее 120 км/ч.
- Узлы: пробитый радиатор (перед ≥ 35) — тяга −18%; двигатель (перед ≥ 70 или кузов < 30) — максималка −15%; разбитое колесо (борт ≥ 40) — уводит в сторону. Узлы видны строкой над панелью машины.
- ИИ: таран одной цели не чаще раза в 4 с, на игроке одновременно не больше двух охотников; если игрок разбил 2+ машин — ИИ +10% урона и +8% скорости; если у игрока кузов < 30% — агрессия к нему −15%.
- Урон оружия ×0,15 от табличного, ловушки (лопасть, пресс) отбрасывают, но не убивают с одного касания. Дерби длится до 4 минут.

## Автотесты

```
cargo test                                   # юнит: урон по Δv, броня, «нет мгновенной смерти», стадии износа, мёртвая зона, реверс
carbang --headless --test start              # 12 машин × 4 сценария ввода: за 3 с после старта только вперёд
carbang --headless --test ram                # таран на 40/80/120/140 км/ч для всех моделей
CARBANG_SEED=11 carbang --headless --test match --map coliseum --mode derby --bots 11 --secs 300   # матч с автопилотом игрока
```

Скриншоты для отчёта: `--res 1920x1080 --screenshot файл.png` (с `--quick --autopilot` или `--test crash`).

## Режимы

- **Карнаж.** Одна жизнь, личный таймер. Время пополняют контрольные точки (+12 с), сбитые пешеходы (+4 с), урон по соперникам и разбитые машины (+30 с). Победа: пройти все круги, разбить всех или очистить улицы.
- **Дерби на выживание.** Пешеходов нет, одна жизнь, побеждает последний на ходу.
- **Бойня.** Воскрешение через 3,5 с с щитом. Побеждает тот, кто первым разобьёт нужное число машин.
- **Охота на пешеходов.** Три минуты, комбо до x5 умножает очки.

| Бизон (пикап) | 6 000 | 2 | Боезапас +35% |

| Оса (болид) | 12 000 | 4 | Нитро восстанавливается вдвое быстрее |

| Каток (трактор с ковшом) | 20 000 | 6 | Урон от взрывов -40% |

| Миксер (бетономешалка) | 28 000 | 8 | Почти не отбрасывает |
| Камчатка (внедорожник) | 32 000 | 9 | Сам встаёт на колёса |

Модели машин: Kenney Car Kit (CC0), подобранные под концепты; инструмент `tools/cars/convert.py` переводит их в формат игры (`assets/cars/*.cbm`): масштаб под габариты машины, «Мэр» удлинён до лимузина, «Миксер» собран из бортового грузовика с вращающимся барабаном. Кузов делится на краску (цвет скина), отделку и стекло, бамперы и двери отрываются, колёса крутятся и поворачиваются. Без папки `assets/cars` машины строятся процедурно, как раньше. Материалы кузова (`tools/cars/bake.py`, `tools/cars/car_textures.py`): сглаженные нормали, запечённое затенение и грязь по вершинам, лак с бликами, царапины (из наклейки повреждений пакета v3), сколы и потёки, резина и хром по палитре, бамперы из рифлёной стали. Корпуса оружия стальные, цвет оружия показан полосой.

Разгон 0–100 км/ч от 4,4 с (Блоха) до 13,6 с (Миксер), максималки от 96 км/ч (Дедуля) до 218 км/ч (Оса). Цифры получены автотестом физики (см. ниже).

## Тюнинг

- **Апгрейды за кредиты** (5 уровней, цена растёт с классом машины): двигатель, броня, шины, подвеска, силовой бампер, закись азота.
- **Бесплатная настройка** для каждой машины: жёсткость пружин, клиренс, стабилизаторы, баланс сцепления осей (дрифт или недостаточная поворачиваемость), передаточные числа, тормозной баланс, скорость руля, электронная стабилизация, автоконтрруление.
- **Оружие** ставится на точки крепления машины (перед, крыша, зад, борта), покупается один раз, качается до 3 уровня (+15% урона и +25% боезапаса за уровень):
  - Швейная машинка: пулемёт, на крыше сам наводится;
  - Гвоздомёт: неуправляемые ракеты;
  - Осиное гнездо: самонаводящиеся ракеты с захватом цели;
  - Сюрприз: мины сзади;
  - Бабушкин чайник: бомба навесом;
  - Ёж: шипы, +60% урона тараном, бьющий в шипы ранится сам;
  - Плуг: отвал, перед крепче на 60%, таран сильнее на 30%;
  - Глушилка: ЭМИ глушит моторы и оружие вокруг;
  - Блин: масляное пятно;
  - Шашлык: огнемёт.
- **Перки** (3 слота, открываются уровнем): Механик, Таранщик, Магнит, Толстокожий, Кровопийца, Барахольщик, Каскадёр, Лёгкий спуск, Вампир, Адреналин, Пироман, Танк, Призрак, Второе дыхание.
- **Покраска**: 19 цветов.

## Бонусы на карте

Ремонт, полный ремонт, нитро, боеприпасы, время, кредиты и ящик «?» со случайным эффектом: двойной урон, неуязвимость, мегатаран, пинбол (соперники отлетают), лунная гравитация, липучка, пружины для прыжков, невидимка, пешеходы-магниты, великаны, заморозка соперников, ракетный залп, кольцо мин. Ящики возрождаются через 18–28 с.

## Карты

- **Бобровая гавань.** Портовый город, причалы, вода, контейнерный двор, краны, грузовой корабль с пандусом и товарняк, который не тормозит.
- **Ржавый рай.** Свалка-лабиринт из сплющенных машин, гидропресс, хафпайп, грязевые ямы.
- **Мясорубка.** Стадион-чаша с наклонными стенами и вращающейся лопастью в центре.
- **Карьер «Глубокий».** Спиральный спуск, террасы, прыжок через пропасть, динамит, самосвал на маршруте.
- **Аэродром «Северный».** Полоса для разгона, ангары насквозь, рулящий лайнер.
- **Неоновый центр.** Ночной город, многоэтажная парковка с прыжком с крыши, эстакада, стройка с ядром-маятником.

## ИИ соперников

У каждого бота свой характер: агрессия, мастерство, тяга к пешеходам, трусость, мстительность, безрассудство. Цель выбирается по полезности: охота (с ограничением, чтобы толпа не набрасывалась на одного), месть обидчику, ремонт и бонусы, пешеходы, бегство на малом здоровье. Маршрут ищется A* по навигационной сетке карты со срезанием углов. Боты тормозят перед поворотами, обходят стены по лучевым щупам, разворачиваются задним ходом, если цель внутри радиуса разворота, разгоняются с нитро на таран, после удара отъезжают для нового разгона, выбираются из застревания и стреляют с упреждением.

## Графика (GFX v2)

- Пост-обработка: тонмаппинг AgX, экспозиция под каждую карту, bloom с низким порогом (фары, неон, искры), встроенная цветокоррекция, виньетка.
- Туман: дистанционный бирюзовый со свечением в сторону солнца; на «Высокой» графике объёмный туман с лучами прожекторов, фонарей и низкого солнца.
- Свет: низкое тёплое солнце или холодная луна, каскадные тени, натриевые фонари, мачтовые прожекторы на арене и аэродроме, настоящие фары у машин ночью.
- Небо и окружение: HDRI Poly Haven на куполе с туманным поясом у горизонта, освещение окружением (отражения неба на кузовах и в лужах); на «Высокой» дополнительно отражения в экранном пространстве.
- Покрытия: текстуры v3 (асфальт, бетон, тротуарная плитка, кирпич, грунт, песок, грязь, скалы, трава, доски, ржавый лист, рифлёный металл, гофра контейнеров) с картами нормалей, шероховатости и AO; поверх запекаются лужи и сырость под погоду карты. Если набора нет, берётся прежний ambientCG. Декали: выбоины, масло, лужи, люки, разметка; после взрывов копоть и воронки, после сильных ударов осколки стекла.
- Модели Kenney: деревья и камни, ржавые остовы машин в стенах свалки и на окраинах, фонарные столбы, конусы, разлетающиеся обломки.
- Повреждения в четыре слоя: вмятины по зонам, оторванные бамперы, двери и колёса (летят по физике), слой износа по стадиям (царапины, грязь, ржавчина, дыры), трещины на стёклах. Пар из пробитого радиатора, дым, огонь, масляные лужи под разбитой машиной.
- Камера: дрожь на скорости и с нитро, рывок FOV на нитро, крен в поворотах, инерционное следование.

Качество графики в настройках: «Низкая» (без теней и bloom), «Средняя» (тени, bloom, FXAA), «Высокая» (всё, включая отложенный рендер, SSR и объёмный туман). Целевая производительность «Высокой»: 60 FPS на RTX 4070 в 1440p; на реальном железе не замерялась.

Папка `assets` рядом с exe обязательна для текстур, неба и моделей. Без неё игра запускается на процедурной графике.

## Интерфейс и звук (ТЗ v2)

- HUD по макету 16:9: таймер, выбито, в игре и очки слева вверху; круглый радар со сканером справа вверху; пять слотов навесного с иконками, боезапасом и шкалой перезарядки слева; панель машины (аватар, кузов, броня) и строка повреждённых узлов внизу слева; лента событий по центру (не шире 32% экрана); аналоговый спидометр 0–220 с передачей N/R/D1–D4 и нитро справа внизу. Масштаб интерфейса — по высоте окна.
- Правила режима — в меню паузы.
- Звук: лупы моторов с питчем по оборотам (тяжёлый мотор у Мамонта и Катка), удары металла с громкостью по Δv (тише 3 м/с не звучат), взрывы со слоем металла, крики пешеходов в пространстве, диктор на отсчёте и в итогах.
- Повреждения: спрайтовые стадии износа (damage_stage1–4 по порогам 75/50/25%), отрывающиеся детали, GPU-искры, дым мотора и пар радиатора (bevy_hanabi).
- Скины: 12 палитр (цвет, металл, шероховатость) и наклейки на двери и капот («Ржавый череп», «Пломбир», «Кровь») — в гараже, вкладка «Покраска».

## Сетевая игра

Хост считает всю физику и правила, клиенты отправляют ввод и получают снапшоты 30 раз в секунду (пешеходы 10 раз в секунду) с интерполяцией. До 8 игроков плюс боты.

1. Хост: «Сетевая игра» → «Создать игру». Открыть UDP-порт 47800 (установщик добавляет правило брандмауэра) или играть в общей сети: LAN, Radmin VPN, ZeroTier, Tailscale.
2. Клиенты: ввести IP хоста → «Подключиться».
3. Хост выбирает карту, режим, число ботов и сложность → «Старт».

Ограничение: клиентского предсказания нет, поэтому на пинге выше 120 мс управление ощущается вязким.

## Сохранения и настройки

`%APPDATA%\CarBang\profile.json` и `settings.json` (Linux: `~/.local/share/carbang`). Настройки: качество графики, полный экран, громкость, дистанция камеры, счётчик FPS, пешеходы-зомби.

## Сборка из исходников

Нужен Rust 1.95+ (Bevy 0.19).

```bash
cargo run --release
```

Ключи командной строки:

```
--quick --map port|junkyard|coliseum|quarry|airfield|downtown --mode carnage|derby|deathmatch|pedhunt --bots N --car ferret
--host                 сразу создать сервер
--connect 1.2.3.4      сразу подключиться
--headless --test physics          автотест физики всех машин
--headless --test battle --map port --secs 90 --bots 8   бой ботов без окна
--headless --test nethost / netclient --connect 127.0.0.1   сетевой тест
```

Кросс-сборка под Windows из Linux: `tools/build_windows.sh` (rustup 1.97, std собирается из исходников той же версии, MinGW-w64), установщик: `makensis installer/carbang.nsi`.

## Устройство кода

| Модуль | Что делает |
|---|---|
| `data.rs` | Все игровые данные: машины, оружие, апгрейды, перки, бонусы, карты, карьера |

| `weapons.rs`, `combat.rs` | Оружие, снаряды, взрывы, урон по зонам, разбитые машины |
| `ai.rs` | Боты |
| `peds.rs`, `powerups.rs`, `rules.rs` | Пешеходы, бонусы, правила режимов, очки и награды |
| `maps/` | Процедурные карты по сиду, навигация, движущиеся ловушки |
| `carmodel.rs`, `effects.rs`, `meshgen.rs` | Модели машин с вмятинами, частицы, процедурные текстуры |

| `net/` | UDP-протокол, сервер, клиент |

Порядок симуляции в фиксированном шаге 120 Гц: ИИ → машины → оружие → урон → правила → физика avian.

## Сборка под Linux

Бинарник собирается под glibc 2.28 (Ubuntu 20.04+, Debian 10+, Fedora 29+, Arch) через zig:

```
pip install ziglang cargo-zigbuild
cargo-zigbuild rustc --release --target x86_64-unknown-linux-gnu.2.28 --bin carbang -- -C link-arg=-Wl,--allow-shlib-undefined
tools/package_linux.sh
```

Флаг `--allow-shlib-undefined` нужен, потому что системные libasound/libudev сборочной машины новее glibc 2.28; на машине игрока берутся её собственные библиотеки. Для запуска нужны драйвер Vulkan, libasound2, libudev1 и X11 или Wayland.
