# CarBang: готовые сборки

Код и ассеты лежат в ветке `main`. Здесь только бинарные сборки, разбитые на части по 30 МБ.

## Linux 0.2.0 (x86_64, glibc 2.28+)

Скачать все файлы из папки `linux-0.2.0` в одну папку, затем:

```
sh join.sh
./CarBang-0.2.0-linux-x86_64/carbang.sh
```

`join.sh` склеивает части, проверяет SHA256 и распаковывает архив. Требования и пакеты для Ubuntu/Debian в `ЗАПУСК.txt`.
